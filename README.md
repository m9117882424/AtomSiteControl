# AtomSiteControl

Browser-based construction site dispatcher simulator inspired by large industrial construction projects.

## MVP goal

The first playable version focuses on a single shift:

- construction site map;
- equipment status panel;
- shift task list;
- active trips table;
- event log;
- basic KPI dashboard;
- local browser-only simulation state.

## Tech stack

- React
- TypeScript
- Vite
- CSS

## Run locally

```bash
npm install
npm run dev
```

## Product idea

AtomSiteControl is not just a game prototype. It is a portfolio-grade industrial simulation showing how dispatching, fleet monitoring, fuel control, idle time analysis and BI dashboards can be combined into one interactive product.
